이 창에서 고친 내용은 저절로 저장되지 않습니다. 고친 뒤 코드 받기를 누르고, 나온 코드를 GitHub의 해당 파일에 붙여넣어야 홈페이지가 바뀝니다.
  1. 탭을 오가며 필요한 내용을 모두 고칩니다 (고친 탭에는 ● 표시가 붙습니다)
  2. 코드 받기 → 복사
  3. GitHub에서 열기 → 연필 버튼 → 전체 선택 → 붙여넣기 → Commit changes
  4. 1~2분 뒤 홈페이지에서 Ctrl+Shift+R로 새로고침

사진과 영상은 맨 오른쪽 사진·영상 탭에서 올리세요. 이름을 자동으로 붙여 주고, 받은 파일을 images/ 폴더에 올리면 끝입니다.

엑셀이 편하시면 엑셀로 내려받기로 지금 탭을 .csv로 저장해 엑셀에서 고치고, 엑셀 불러오기로 다시 읽어 올 수 있습니다. 첫 줄(머리글)과 id 칸은 건드리지 마시고, 새로 추가한 줄은 id를 비워 두세요. 그다음은 2번부터 똑같습니다.
